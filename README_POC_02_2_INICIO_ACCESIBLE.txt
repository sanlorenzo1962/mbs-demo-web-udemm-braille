CAMBIOS RESPECTO DE POC 02.1

1. Los grupos Modo / Idioma / Tema / Voz educativa ahora usan controles
   de selección exclusiva tipo radio.
   Motivo: es la semántica correcta para opciones mutuamente excluyentes
   y mejora el anuncio de Narrador/NVDA.

2. Etiquetas accesibles de idioma:
   ES -> Español
   PT -> Portugués
   EN -> Inglés
   FR -> Francés
   Visualmente se conservan ES / PT / EN / FR.

3. La pantalla inicial continúa SIN TTS propio del MBS.
   La navegación depende del lector de pantalla del usuario.

4. Tema claro con contraste reforzado:
   - texto principal y secundario más oscuro;
   - bordes más definidos;
   - selección verde más oscura;
   - mejor diferenciación entre fondo, panel y botones.

NOTA DE NAVEGACIÓN
Con controles radio, el comportamiento estándar de teclado es:
- TAB entra/sale de cada grupo;
- flechas cambian la opción dentro del grupo;
- Narrador/NVDA informa seleccionado/no seleccionado.

No se agregó persistencia.
Inicial e Intermedio siguen sin integrar en este POC.
