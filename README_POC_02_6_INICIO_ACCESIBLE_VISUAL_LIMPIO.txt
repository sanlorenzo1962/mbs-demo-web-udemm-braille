MBS_DEMO_MODOS_POC_02_6_INICIO_ACCESIBLE_VISUAL_LIMPIO
Fecha: 2026-10-03

OBJETIVO
Corregir el desajuste visual introducido por la superposición de estilos
entre POC 02.4 y POC 02.5.

CORRECCIONES
- Se eliminan completamente los indicadores heredados ○ / ●.
- Se conserva únicamente un ✓ en la opción seleccionada.
- El ✓ se coloca a la derecha sin desplazar el texto.
- Se recompone el padding y la alineación de los labels.
- Se mantiene la navegación accesible validada:
  TAB por grupos y flechas dentro del grupo.
- Inicio sigue sin TTS propio del MBS.
