MBS_DEMO_MODOS_POC_03_2_BARRA_ACCESIBILIDAD_INCREMENTAL
Fecha: 2026-10-04

BASE
POC 03.1 – Accesibilidad visual global.

OBJETIVO
Compactar los controles visuales y hacer incremental el tamaño de texto,
manteniendo coherencia visual con la página institucional MBS.

CAMBIOS
- Se reemplazan los bloques grandes Tema / Tamaño / Contraste por una
  única barra "ACCESIBILIDAD VISUAL".
- A− disminuye el texto en pasos de 10%.
- A restablece el tamaño a 100%.
- A+ aumenta el texto en pasos de 10%.
- Rango permitido: 80% a 140%.
- Se muestra el porcentaje actual.
- Botón ◐ alterna contraste Normal / Alto.
- Botón ☀ alterna tema Oscuro / Claro.
- Botón ↺ restablece tamaño 100%, contraste normal y tema oscuro.
- Los botones tienen etiquetas accesibles para lectores de pantalla.
- "Intermedio" conserva su nombre y recibe mayor ancho dentro del selector.
- No se modifica la lógica pedagógica del Modo Inicial.
- No se agrega persistencia todavía.

PRUEBA SUGERIDA
1. Pulsar varias veces A+ hasta 140%.
2. Pulsar varias veces A− hasta 80%.
3. Verificar "Intermedio" en todo el rango.
4. Probar contraste alto.
5. Probar tema claro/oscuro.
6. Entrar a Modo Inicial y comprobar que el aumento también se aplica allí.
7. Volver a Inicio y verificar que el valor se conserva durante la sesión.
