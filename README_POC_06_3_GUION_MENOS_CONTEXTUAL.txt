MBS_DEMO_MODOS_POC_06_3_GUION_MENOS_CONTEXTUAL
Fecha: 2026-10-05

CAMBIO ÚNICO
La celda 3-6 conserva el carácter visual "-" pero la Voz MBS lo nombra
según el contexto:

- Texto: guion / hífen / hyphen / tiret.
- Modo NÚM.: menos / menos / minus / moins.

El mismo criterio se mantiene tanto al ingresar el signo como al pulsar SP
y escuchar el deletreo final.

NO SE MODIFICÓ
- tablas Braille;
- carácter visual "-";
- demás signos;
- lógica numérica;
- Inicial;
- Avanzado;
- exportaciones;
- accesibilidad.

PRUEBA RECOMENDADA
1. En texto: 3-6 -> debe mostrar "-" y decir "guion".
2. NÚM. 3-4-5-6 -> 3-6 -> debe mostrar "-" y decir "menos".
3. Pulsar SP -> el deletreo final debe conservar la misma interpretación.
