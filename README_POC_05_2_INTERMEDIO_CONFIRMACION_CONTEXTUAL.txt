CAMBIO ÚNICO RESPECTO DE POC 05.1
Al finalizar con SP, la Voz MBS ya no envía al sintetizador únicamente la
palabra o número aislado. Usa una frase contextual:

ES: “Escribiste …”
PT: “Você escreveu …”
EN: “You wrote …”
FR: “Vous avez écrit …”

OBJETIVO
Evitar interpretaciones automáticas indeseadas del TTS del navegador para
palabras cortas o abreviaturas. Ejemplo observado: “cal” podía ser leído como
“calorías”.

NO SE MODIFICÓ
- lógica Braille;
- números;
- MAY./NÚM.;
- tonos;
- diseño visual;
- controles hablados;
- Modo Avanzado.
