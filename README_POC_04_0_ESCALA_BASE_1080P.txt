Fecha: 2026-10-04

BASE
POC 03.9 – Fondo overlay fijo.

CRITERIO GENERAL ADOPTADO
A partir de esta versión se valida MBS con:
- navegador al 100%;
- tamaño MBS normal;
- resolución de referencia 1920x1080;
- sin scroll horizontal;
- la pantalla principal debe ser utilizable sin depender del zoom del navegador;
- los aumentos de accesibilidad pueden generar scroll vertical.

CAMBIOS
PORTADA
- Reducción moderada del tamaño físico del contenedor.
- Menos espacio vertical entre bloques.
- Logo y márgenes más compactos.
- Se conserva la tipografía útil.

MODO INICIAL
- Reducción de diámetro físico de los seis puntos.
- Menor separación vertical y horizontal.
- Teclado visual más compacto.
- Panel de nivel de tono más compacto.
- Se mantiene legibilidad y foco.

NO SE MODIFICA
- TTS.
- Nivel de tono 1–10.
- Navegación.
- Intermedio provisional.
- Avanzado validado.
- Accesibilidad visual 80–140%.

OBJETIVO
Que la apariencia a Chrome 100% se aproxime a la proporción visual que
antes requería 75–80% de zoom del navegador.
